01 / THE QUESTION

THE RESEARCH THESIS

Can examples become
an executable idea?

Templated financial questions often repeat a hidden computational structure. Instead of manually writing a solver for each template, this work asks whether a system can infer an arithmetic program from labeled examples.

05 / THE FRONTIER

LIMITATIONS ARE PART OF THE RESULT

A verified formula can
still be the wrong model.

01 / COVERAGE

Bounded search

Long numeric lists, deeper formulas, and enumerated answers challenged the search space.

02 / GENERALIZATION

Hidden templates

A learner dependent on examples for a template cannot automatically infer a rule for a template it has never encountered.

03 / REPRODUCIBILITY

Environment dependencies

The archived scripts include machine-specific paths and organizer-provided dependencies; the code is not yet a turnkey reproduction package.

THE NEXT RESEARCH FRONTIER Expand coverage without sacrificing verifiability.

Structural priors · richer program grammars · calibrated uncertainty · stronger out-of-template evaluation
