01 RESEARCH THESIS

THE QUESTION

What if financial reasoning could be learned as a program?

Templated financial questions often hide a repeatable computational structure. Instead of manually writing a solver for every template, this work investigates whether a system can infer the underlying arithmetic expression from a small set of labeled examples.

The central idea is programming by example: discover a candidate expression, test it against known cases, reuse intermediate reasoning steps, and verify its arithmetic exactly before returning an answer.

04 LIMITATIONS & RESEARCH FRONTIER

WHAT THE RESULTS TEACH US

A verified formula can
still be the wrong model.

01 / COVERAGE

Search-space limits

Long numeric lists, deeper formulas, and enumerated answers challenged the bounded expression search, even for templates represented in the released examples.

02 / GENERALIZATION

Unseen templates

A learner that depends on labeled examples for a template cannot automatically infer the intended program for a template it has never encountered.

03 / REPRODUCIBILITY

From artifact to system

The archived scripts include machine-specific paths and organizer-provided dependencies. A clean environment and path configuration are still required for turnkey reproduction.
